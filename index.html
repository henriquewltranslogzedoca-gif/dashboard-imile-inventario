Ajustar classificação dos status

Uma regra por linha no formato: texto do scan = grupo. Grupos válidos: Entregue, Em rota, Piso, Ocorrência, Recebido, Descarregado, Outros. As regras são aplicadas de cima para baixo; a primeira correspondência prevalece. Alterações são salvas neste navegador.

Dados mantidos no seu navegador. Carregue uma nova exportação para atualizar o painel; o arquivo não é enviado para um servidor. O total de cada grupo usa o último scan de cada Waybill.
